# 电路工作台使用说明

原项目：C++ / wxWidgets 桌面应用。新版继续使用原 t1.sln / t1.vcxproj。

## 启动
双击项目根目录“启动编辑器.cmd”，或运行 bin\CircuitWorkbench.exe。
x64\Debug\t1.exe 同样为新版程序。

## 快速上手
1. 左侧点击“载入全加器示例”，按 F5。默认 1+1+0 得到和 0、进位 1。
2. 双击输入元件切换 0/1，再按 F5 重新计算。
3. 元件库点选元件，然后点击画布放置。放置完成自动返回选择模式。
4. 点击“连线”，从引脚按住拖到目标引脚。导线自动按水平、垂直折线连接。可从既有导线引出分支。
5. 选择模式下拖动元件；双击编辑名称或注释。选择元件、导线段或文字后按 Delete 删除。
6. Ctrl+Z 撤销，Ctrl+Y 重做，Esc 取消当前操作。鼠标滚轮缩放，中键拖动画布，Ctrl+0 恢复视图。
7. Ctrl+S 保存，Ctrl+O 打开，Ctrl+Shift+S 另存为。新建、打开、关闭前会检查未保存修改。

## 电路语义
- 使用 IEC 方框逻辑符号：& 为与，≥1 为或，=1 为异或，输出端小圆代表取反。
- 全加器从上到下为 A、B、Cin 输入；右上输出 S，右下输出 Cout。
- 导线端点或引脚落在导线上会形成电气连接；两条导线只有内部交叉时不连接。
- 悬空输入、多输出驱动同一网络、反馈回路会阻止仿真并给出提示。
- 当前支持组合数字逻辑的稳态计算；不提供时序、时钟、存储元件或模拟电路瞬态分析。
- 拖动会自动补线避让其他网络；位置无法安全接线时会保留前一个有效位置。
- 修改电路后清除旧仿真显示，按 F5 更新。

## 文件与导出
- 新版 .circuit 和 .net 使用 UTF-8 文本格式（版本 2），保存中文名称、注释、输入电平和连线。
- 保存采用临时文件提交；无效文件先完整校验，不会覆盖当前画布。
- 可读取旧 CIRC v1 和原坐标网表。旧版保存程序曾错误写入 Unicode 字符的字节数；已经丢失的中文不能还原。
- 新版统一了元件引脚和外形。导入旧版文件后需检查旧导线端点并重新吸附到新引脚，再仿真确认。
- SPICE 导出为 0/1 V 行为电源模型，包含实际连接与逻辑表达式。已检查文件生成，未使用外部 SPICE 引擎运行；不等同于器件级电气模型。

## 构建与自检
本机已验证 Visual Studio 2022 v143、Windows SDK、C:\wxWidgets-3.2.2.1 的 x64 Debug 静态库。
在 PowerShell 中执行：

    .\build.ps1
    .\build.ps1 -Test

也可在 Visual Studio 打开 t1.sln，选择 Debug / x64。其他平台或 Release 需要另行准备对应 wxWidgets 库。
项目使用 C++17、UTF-8 源码和宽字符界面文字；调试符号使用 /Z7，关闭链接器 PDB 生成，以绕过本机 MSPDB140 版本冲突。

已通过 63 项回归检查，记录见 regression.txt。覆盖全部基本门真值、全加器 8 种输入、折线和分支、拖动及撤销重做、中文文件和网表往返、无效文件保护，以及悬空、冲突、反馈和交叉不连接。

运行程序需要本机现有的 MSVC Debug 运行环境；当前交付为本机可运行版本，不是面向未安装开发环境机器的安装包。
